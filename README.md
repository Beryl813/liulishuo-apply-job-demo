# 流利说 WorkBuddy 全流程 Demo · V13

## 本版变化

1. 用户在 WorkBuddy 的聊天里完成全部自我介绍/面试问答的定稿展示，不再跳独立定稿确认页面。
2. 完成定稿后，将**演示 Buddy 自定义前端**的聊天输入区切换成「连接流利说训练服务」卡片，用户可主动点击，也可返回继续修改。
3. 点击「连接并继续」→ 右下角连接中提示 → 流利说登录授权演示页（参考官方页面布局）→ 模拟授权成功使用指南页 → 流利说独立训练承接页。
4. 演示流程中的账号表单与二维码都是非真实的占位；不会采集号码、发送验证码、进行 OAuth 或支付，也不会将稿件自动传入真实 App。

## 本地启动

浏览器打开 `index.html`，点击「使用示例」进入聊天，输入 `60 秒`、`准备面试题`、`直接给我全部答案`、`最终定稿`。
在底部点击「连接并继续」，然后点击「模拟登录并授权成功」，进入演示授权成功页，再点击「打开流利说训练页面」。

## 实际落地边界

WorkBuddy 原生聊天输入框是否能由应用直接替换，需宿主前端或 WorkBuddy 自定义 Buddy 应用页面支持；**单靠 SKILL.md 不可以**。纯 Skill/Expert 降级为自然语言引导 + 已确认可用链接。
联调还需要 WorkBuddy 与流利说的授权交接、真实登录域、App Deep Link、会话安全传稿、课程二维码以及转化归因埋点。
